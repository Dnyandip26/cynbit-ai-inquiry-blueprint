# Screenshot capture instructions

This folder is intentionally left empty of screenshot artifacts. Capture your final demonstration screenshots locally and save them here only when you are ready to share them.

## Recommended screenshots to capture

1. Homepage / inquiry form
2. Service matches tab
3. AI analysis tab
4. Blueprint tab
5. Downloaded Markdown output (if using the export button)

## Recommended workflow

1. Activate the project environment.
2. Start the app with:
   ```bash
   streamlit run app.py
   ```
3. Open the local Streamlit page in a browser.
4. Enter a realistic demo inquiry.
5. Click the Groq analysis button.
6. Take screenshots of the main application panels.
7. Save the screenshots in this folder using descriptive file names such as:
   - `01-inquiry-form.png`
   - `02-service-matches.png`
   - `03-ai-analysis.png`
   - `04-blueprint.png`

## Important notes

- Do not fabricate screenshots or include fake application captures.
- Keep screenshots limited to the local demo environment.
- Do not include confidential or personal data in captured images.
- Ensure any exported markdown or CSV files are from local demo runs only.
